# Dovetale Knowledge OS & Study Atlas
### Business & Marketing Infrastructure — Executive Study Suite

An interactive, responsive, dark-themed personal study portal compiling all 22 internal operational frameworks, technical specifications, and website blueprints for **Dovetale**.

---

## 🚀 Quick Start

Open `index.html` in any modern web browser:
- **Windows:** Double-click `index.html` in File Explorer
- **Browser URL:** `file:///path/to/Dovetale-study/index.html`
- **Zero Dependencies:** Fully self-contained, offline-ready with local storage persistence.

## 🛠️ Study Portal Features

- **Executive Pipeline Map:** End-to-end interactive flowchart of the 10 Pillars across 4 tiers.
- **562 Interactive Checklists:** Actionable tasks with auto-saving checkmarks via `localStorage`.
- **Global Instant Search (`Ctrl + K` / `Cmd + K`):** Real-time keyword search across 47,334 words with snippet previews.
- **Executive Takeaway Cards:** Synthesizing module classifications, deliverables, and completion rates.
- **ASCII Box Diagram Enhancer:** High-contrast terminal cards with one-click clipboard copying.
- **Personal Study Notes Pad:** Auto-saved private notes per module stored locally.
- **Sticky Table of Contents:** Fast section jump navigation on desktop.
- **Fully Responsive:** Fluid drawer navigation on mobile and tablet devices.
